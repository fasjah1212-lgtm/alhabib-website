# موقع مصنع الحبيب للزجاج والألمنيوم

تصميم جديد لموقع [alhabibfactory.com](https://alhabibfactory.com): عربي من اليمين لليسار، سبع صفحات، بألوان الموقع الأصلي.

## وش صيغة الموقع؟

موقع ثابت (Static) مكتوب بـ **HTML و CSS و JavaScript** فقط. ما يحتاج سيرفر ولا قاعدة بيانات، ويشتغل على أي استضافة ترفع ملفات.

| الملف | الصفحة |
|---|---|
| `index.html` | الرئيسية |
| `products.html` | منتجاتنا |
| `works.html` | أعمالنا |
| `services.html` | خدماتنا |
| `branches.html` | فروعنا |
| `franchise.html` | الامتياز التجاري |
| `contact.html` | تواصل معنا |

- `site.css` التنسيق، و `site.js` الحركة (يستخدم مكتبة GSAP من cdnjs).
- `img/` الصور والشعارات، و `vid/` مقاطع المنتجات.
- `src/` ملفات المصدر لبناء الصفحات من جديد (للمطور فقط).

## المعاينة على جهازك

```bash
python3 -m http.server 8000
# افتح http://localhost:8000
```

## النشر

**GitHub Pages (رابط معاينة مجاني):** من إعدادات المستودع > Pages > Source: `Deploy from a branch` > الفرع `main` والمجلد `/ (root)` ثم Save. بعد دقيقة يطلع الرابط `https://<اسم الحساب>.github.io/<اسم المستودع>/`.

**استضافة عادية (cPanel وغيرها):** ارفع كل الملفات والمجلدات ما عدا `src` و `README.md` إلى مجلد `public_html`.

## إعادة البناء (للمطور)

الصفحات تنبني من `src/build.py` (Python 3):

```bash
python3 src/build.py
cp src/out/standalone/*.html src/out/standalone/site.css src/out/standalone/site.js .
```

الشعارات في `src/clients/<slug>.png` ومقاطع المنتجات في `src/vid/`.
